# Reference Docs

This folder preserves historical or imported project context.

Reference docs may contain stale assumptions. Before using one to guide current
implementation, compare it against:

- `AGENTS.md`
- `docs/rebuild/HANDOFF.md`
- `docs/rebuild/CURRENT_STATUS.md`
- `docs/rebuild/DECISIONS.md`

If a reference doc conflicts with the living rebuild docs, treat the living
rebuild docs as current.
